Milestone-2-collaboration

This project implements a university enrollment system which includes
course capacity, waitlists (using a linked queue), sorting,
recursive binary search.

Files:
-Milestone.py: Contains Student, Coruses, and University classes
-Milestone2.py: Contains linkedQueue, Enrollment Record, and binary search
-test_milestone2.py: Unit tests for functionality
-demo.py: Demonstrates enrollment, waitlist, sorting, and dropping
-milestone2_report.txt: Contains time complexity analysis

How to run demo:
python3 demo_milestone2.py

How to run tests:
python3 -m unnittest test_milestone2.py
